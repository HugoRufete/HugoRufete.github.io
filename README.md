# HugoRufete.github.io

Hugo Rufete's personal portfolio: a static, work-first site about immersive experiences, technical design and game/XR development.

Published from the `main` branch with GitHub Pages. No build step or runtime dependencies.

- `index.html` — portfolio homepage.
- `projects/<slug>/index.html` — individual project pages.
- `projects/<slug>/media/` — active multimedia source.
- `css/`, `js/` — styles and vanilla rendering.
- `AGENTS.md` and `docs/` — working rules, preferences, CV profile, project contracts and progress log.

See `docs/WORKFLOW.md` before making changes.
